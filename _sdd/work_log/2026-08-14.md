## 10:04 Codex 설치 원격 한 줄을 README 기본 경로로 (Opus 5)

- **무엇/왜**: "codex 스킬 설치를 uvx로 한 번에 못 하나?"라는 질문에서 출발. 조사 결과 **uvx는 불필요** — `tools/install-codex-skill-bundle.py`는 서드파티 의존성 0(표준 라이브러리만)이고 `__file__`·로컬 경로를 참조하지 않으며 항상 GitHub zipball을 받아 설치하므로, clone 없이 원격 실행해도 정상 동작한다. uvx를 쓰려면 pyproject + `[project.scripts]` 패키징이 필요한데 격리 venv의 이점이 없고(의존성 0) 버전 핀은 이미 `--ref`가 제공한다 — 순비용이라 기각.
- **결과**: README Option A를 원격 한 줄 우선으로 재구성 — `curl -fsSL <raw URL> | python3 -` 기본, `uv run <raw URL>` 대안, clone 시 로컬 경로 실행은 동등 경로로 후치. 예시 블록에 원격 실행 시 인자 전달법(`| python3 - --dry-run`) 1줄 주석 추가. 기존 문면은 clone 전제로 읽혔던 것이 실제 개선점이었다.
- **검증**: 4경로 전부 `--dry-run` 실행 확인(clone 없는 `/tmp`에서 1·2·3, repo에서 4) — curl 파이프 / `uv run` URL / 인자 전달(`--force` 부여 시 `unchanged` → `would replace`로 전환) / 로컬 경로. current spec(`main.md`·`components.md`)에는 이 스크립트 언급이 없어(`_sdd/spec/prev/` 스냅샷 한정) spec-sync 불요.
