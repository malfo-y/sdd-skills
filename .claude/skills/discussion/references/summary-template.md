# Discussion Summary Template

요약 형식의 단일 소스다. 아래 fenced template의 필수 섹션·표 열을 유지하고 `[...]` 슬롯을 실제 값으로 채운다. 목록·표 행은 실제 개수만큼 반복하거나 삭제하며, 필수 섹션에 항목이 없으면 `없음`을 쓴다. 구조와 의미를 유지해 사용자의 언어로 표시한다. 작성 안내·예시 슬롯은 완성 파일에 남기지 않는다.

- 결정 근거 유형은 `코드 확인`(로컬 파일·코드 직접 확인) / `외부 자료`(조사한 외부 근거) / `사용자 판단`(의도·선호·선택) / `미검증 가정`(확인 전 전제)이다. 한 결정이 여러 근거에 의존하면 근거별 유형을 적는다. 재검토로 변경·강등된 결정은 이유와 변경 내용 한 줄을 남긴다.
- 미결에는 `out-of-scope`(범위 밖) / `needs-data`(외부 근거 대기) / `deferred-deliberately`(의도적 보류) / `blocked-by:Q<n>`(다른 미결에 의존) 중 맞는 카테고리를 적는다. 분류할 근거가 없으면 `미확인`으로 남기고 필요한 정보를 설명한다. 사용자 확인 없는 추정 분류에는 `(auto-labeled, please review)`를 붙인다. 라벨을 채우려고 없는 의존·보류 의사를 만들지 않는다.
- 상태와 검증 결과는 SKILL.md의 정리와 종료·Final Check를 따른다.
- 조건부 섹션: `기각한 대안`은 실제 기각한 대안이 있을 때, `후속 핸드오프`는 후속 스킬·구현으로 이어질 때 포함한다. `부록: 대화 로그`는 사용자가 상세 로그를 요청했거나 결정 경위를 라운드별로 복원해야 하는 감사 요구가 있을 때만 포함한다. 감사 요구는 사용자 요청·프로젝트 규약에서 확인하며 단순히 토론이 길다는 이유로 추정하지 않는다. 조건에 해당하지 않으면 섹션 전체를 생략한다.
- 로그를 포함하면 실제 기록이 있는 라운드만 반복한다. 기억나지 않는 질문·선택지·답변은 만들어내지 않고 누락을 표시한다.

```markdown
# 토론 요약: [토픽]

**날짜**: [YYYY-MM-DD]
**상태**: [정상 종료 또는 중단·미완료]
**검증 결과**: [검토한 범위, 미충족 AC와 이유가 있으면 표시]

## 토론 배경 및 초기 콘텍스트 (Background / Initial Context)
- **사용자 문제 제기와 배경**: [무엇을 왜 판단하려는지]
- **현재 상태**: [확인한 현황]
- **범위와 제외 범위**: [다룬 범위와 사용자 지정 선택·제외]
- **수집한 근거**: [파일·자료 포인터와 판단에 영향을 주는 발견]

## 핵심 논점 (Key Discussion Points)
1. [논점]: [검토 결과와 중요한 가정·위험]

## 결정 사항 (Decisions Made)
| # | 결정 | 근거 (유형) | 관련 논점 |
|---|------|------------|----------|
| [번호] | [결정] | [근거와 유형] | [관련 논점] |

### 기각한 대안
- [대안]: [기각 사유]

## 미결 질문 (Open Questions)
| # | 질문 | 카테고리 | 맥락 / 의존 |
|---|------|----------|-------------|
| [Q번호] | [질문] | [카테고리] | [필요한 근거·다음 행동·의존·추정 표시] |

## 실행 항목 (Action Items)
| # | 항목 | 우선순위 | 담당 |
|---|------|---------|------|
| [번호] | [항목] | [High/Medium/Low 또는 미정] | [담당 또는 미정] |

### 후속 핸드오프 (Handoff)
- **목표**: [후속 작업의 관찰 가능한 완료 기준]
- **변경 금지 제약**: [후속 작업의 경계]
- **검증**: [성공을 확인할 방법]
- **중단 조건**: [멈추고 보고해야 하는 경우]

## 부록: 대화 로그 (Conversation Log)

### Round [실제 번호]
**Q**: [실제 질문]
**Options**: [실제 선택지 또는 사용하지 않음]
**A**: [사용자 응답 요약]
**Follow-up**: [검토 결과 또는 방향 변경]
```
