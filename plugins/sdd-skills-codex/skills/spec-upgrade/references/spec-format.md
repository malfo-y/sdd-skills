# Spec Format Reference (Current Model)

## Global Spec Core

| Order | Section | Purpose | Required |
|------|---------|---------|----------|
| 1 | Background & High-Level Concept | 문제 framing과 repo 관점 고정 | Yes |
| 2 | Scope / Non-goals / Guardrails | 책임 범위와 공통 경계 고정 | Yes |
| 3 | Core Design & Key Decisions | 유지해야 할 장기 판단 고정 | Yes |

Optional support layers:

- reference information
- guide links
- compact Strategic Code Map or supporting surface link
- repo-wide invariant wording inside guardrails or key decisions
